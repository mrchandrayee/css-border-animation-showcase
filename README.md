## Project structure
- `index.html` — ten preview/code pairs and page structure
- `style.css` — full layout and all ten CSS animations
- `script.js` — replay control
- `README.md` — this guide

## Run
Extract the ZIP and open `index.html` in a modern browser. No dependencies or build process required.

## About code extraction
This video shows a rendered code-and-preview showcase, not the original source repository. The visible titles and readable CSS declarations were transcribed as closely as possible. Some long code lines are partially obscured or too small to read in the recording; those portions and the complete runnable implementation have been reconstructed to reproduce the displayed effects, not recovered byte-for-byte from the original project.
